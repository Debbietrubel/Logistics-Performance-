Logistics Operations & Performance Dashboard

Overview
Interactive Power BI dashboard built as a capstone project 
analysing a 14 table logistics database covering 85,410 trips 
and $298.6M in revenue across 2022–2024.

Dashboard Preview

Page 1 — Revenue & Customer Analysis
Page 2 — Maintenance & Drivers Performance

Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Modelling — Star Schema

Data Model
14 tables | 16 relationships | Star schema
Central fact tables: LOADS and TRIPS
Dimension tables: CUSTOMERS, DRIVERS, TRUCKS, 
TRAILERS, ROUTES, FACILITIES

Key KPIs
Metric Value
Total Revenue $298.62M
Total Profit $197.30M
Total Operating Cost $101.32M
Total Trips 85,410
Total Fuel Cost $95.59M
Average Fleet MPG 6.50
Active Trucks 92
Revenue Per Mile $2.44
On-Time Delivery Rate 44.6%

Key Insights
- Charlotte → Portland is the highest-profit route at $11.2M
- Contract customers drive 37.6% of revenue ($112M) most predictable income segment
- Revenue of $298.62M is 2.95× the $101.32M operating cost
- On-time delivery rate of 44.6% is the critical operational risk
- Freightliner has the highest maintenance cost at $1.1M fleet-wide

How to Open
1. Download the .pbix file
2. Open Power BI Desktop (free from microsoft.com)
3. Use the Year slicer to filter by 2022, 2023 or 2024
4. Use the Booking Type slicer to filter by contract category
